# Activité Pratique 2 — MVC, Spring Data JPA & Hibernate
## Projet

| Projet | Description |
|--------|-------------|
| [products-mvc](products-mvc/) | Application web Spring Boot MVC avec Thymeleaf, Spring Security, Spring Data JPA et Hibernate — gestion de produits avec authentification et autorisation |

## Technologies utilisées

- **Spring Boot 3**
- **Spring MVC** — couche web
- **Spring Data JPA / Hibernate** — persistance des données
- **Spring Security** — authentification & autorisation
- **Thymeleaf** + `thymeleaf-extras-springsecurity6` — moteur de templates
- **Thymeleaf Layout Dialect** — mise en page réutilisable
- **Bean Validation** — validation des formulaires
